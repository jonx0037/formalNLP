# formalNLP

**The mathematics of language** — the fifth site in the formal series
([formalML](https://formalml.com), [formalCalculus](https://formalcalculus.com),
[formalStatistics](https://formalstatistics.com), [formalRAG](https://formalrag.com)).

Theorem-bearing explainers on the statistics of text, language modeling, representations,
attention and transformers, decoding, classification and sentiment, information extraction and
knowledge graphs, text mining, and evaluation. Every topic ships three pillars: rigorous KaTeX
mathematics, an interactive D3 visualization, and a verified Python notebook.

> **Status:** prelaunch. The site deploys from `main` with `noindex` until all 28 topics and the
> capstone are published.

## Develop

```bash
pnpm install
pnpm dev          # http://localhost:4321
pnpm test         # unit tests
pnpm build        # production build + Pagefind
```

See [`CLAUDE.md`](CLAUDE.md) for conventions and [`STARTER-PROMPT.md`](STARTER-PROMPT.md) for the
per-topic authoring workflow.
